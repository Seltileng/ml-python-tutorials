# AIMLCLASS Codebase

This repository contains various Jupyter Notebooks and resources for machine learning and artificial intelligence projects. Below is an overview of the key files and their purposes.

## Project Structure

- **`house_price_regression.ipynb`**: A notebook for predicting house prices using regression models. Includes data preprocessing, model training, and evaluation.
- **`house_pricing_prediction_LinearRegression.ipynb`**: Focuses on linear regression for house price prediction.
- **`house_pricing.ipynb`**: Another notebook for house price analysis and prediction.
- **`sporting_hits.ipynb`**: A notebook analyzing sporting data, including iterative optimization and preprocessing.

## Key Features

- **Machine Learning Models**: Implements regression models using `scikit-learn`.
- **Data Analysis**: Includes data exploration and preprocessing steps.
- **Visualization**: Provides insights through data visualization techniques.
